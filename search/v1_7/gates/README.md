Rendered screening interfaces of this version: the pages a reviewer actually used to answer the
filters over the worked list in `../automated/records/`. They are generated by
`../scripts/gera_gate_*.py` and `../scripts/gera_manual_revisor2.py`, and they are kept because a
screening interface that no longer exists cannot be shown to have asked what the protocol says it
asked.

Later versions do not carry copies. A version that re-screens generates its own.
